# Kedbyte — Brand Assets

Ready-to-use logo files for decks, email signatures, social profiles, and docs.
All PNGs have transparent backgrounds.

| File | Use case |
|------|----------|
| `kedbyte-lockup.png` | Horizontal logo + wordmark — slides, headers, email signatures |
| `kedbyte-mark-cyan.png` | K monogram (white + cyan accent) — app icon, avatars on dark bg |
| `kedbyte-mark-white.png` | K monogram (solid white) — use on colored/photo backgrounds |
| `kedbyte-icon.png` | Rounded app icon — favicon, social profile picture |

## Colors
- Background / ink: `#050505`
- Surface: `#121212`
- Accent (cyan): `#00F0FF`
- Text primary: `#FFFFFF` · secondary: `#A1A1AA`

## Typography
- Headings: **Cabinet Grotesk**
- Body: **Satoshi**
- Mono / technical: **JetBrains Mono**

## Usage notes
- Keep clear space around the mark equal to the height of the "K".
- Prefer the white mark on photos/colored fields; cyan-accent mark on dark UI.
- Don't stretch, recolor, or add effects to the logo.
